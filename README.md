# c_elegans_analysis
Analysis done for the arxived work, "Developmental Continuity of Brain Network Core Organization in C. elegans" [doi: https://doi.org/10.64898/2026.06.12.730308](https://www.biorxiv.org/content/10.64898/2026.06.12.730308v2). This directory contains the analyses scripts. The data folder has two containers: raw and processed. The former contains the data pertaining to the connectivity, neuron types etc taken from Witvliet; birth time data taken from Kaiser (2011) and wormweb.org; and lineage data taken from wormatlas.org and wormbase.org. The processed folder contains the data generated from my analyses pickled for further use in subsequent analyses.
